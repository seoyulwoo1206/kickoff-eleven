# 클럽팀 데이터 작성 규칙

파일: `<리그><번호>.ts` (예: `EPL1.ts`) — `export default` 뒤에 백틱 글 하나. 한 파일에 여러 팀. 읽는 코드는 `src/data/clubs.ts`(`parseClubs`), 검증은 `npx tsx tools/validate-clubs.ts [파일 이름…]`.
국가대표(`teams/<CODE>.json`)와 달리 선수마다 6대 지표를 적지 않고 **종합(ovr) 하나 + 꼬리표**만 적는다 — 포지션 틀로 6대 지표를 전개한다.

```ts
export default `
@MCI|맨체스터 시티|solid|#6cabdd|#ffffff|#ffffff|#1f1f1f|4-3-3|31,3,5,24,82,16,20,8,47,9,10|2026-11-22|https://en.wikipedia.org/wiki/Manchester_City_F.C.
31|에데르송|Ederson|GK|BRA|33|188|L|86|
9|홀란|Erling Haaland|ST|NOR|26|195|L|91|pac+ phy+ pas- w3 s3
47|필 포든|Phil Foden|RW|ENG|26|171|L|87|dri+ pas+ alt:CAM,LW w4
…
`;
```

## 팀 머리줄 (`@`로 시작, 칸은 `|`)
`@코드|한글 팀 이름|무늬|c1|c2|sh|gk|포메이션|선발 등번호 11개|asOf|출처`
- **코드**: 대문자 3글자, 전체에서 겹치지 않게(국가대표 코드 KOR·ENG·GER 등과도). **한글 팀 이름**: 국내 언론 표기(맨체스터 시티, 토트넘 홋스퍼, 브라이턴).
- **무늬**: `solid` `stripes`(세로줄) `hoops`(가로줄) `half`(반반) `sash`(사선) `chevron` `check` 중 하나. **c1** 주 색·**c2** 보조 색·**sh** 하의·**gk** 키퍼 색 — `#rrggbb`. 홈 유니폼의 색만 비슷하게(엠블럼·스폰서·실제 디자인은 넣지 않는다).
- **포메이션**: `src/data/formations.ts`의 열쇠 중 하나. **선발**: 그 포메이션의 슬롯 순서대로 등번호 11개를 쉼표로(0번 슬롯 = GK, 그다음 수비 왼쪽→오른쪽, 미드필더, 공격). 요즘 주전 기준.
- **asOf**: 명단을 확인한 날짜(YYYY-MM-DD). **출처**: 실제로 읽은 주소(여럿이면 띄어쓰기).

## 선수 줄
`등번호|한글 이름|영문 이름|포지션|국적|나이|키|주발|종합|꼬리표`
- 팀당 **23~26명**, GK 2명 이상(되도록 3명). 1군 주요 선수 위주. 등번호 1~99, 팀 안에서 겹치지 않게.
- **한글 이름**: 국내 언론 표기(홀란, 더 브라위너, 살라). **영문 이름**: 통용 표기(Erling Haaland).
- **포지션**: GK CB LB RB CDM CM CAM LM RM LW RW ST CF.
- **국적**: FIFA 3글자 코드(ENG, BRA, NOR …) — 선수 겉모습(피부·머리색 분포)에만 쓴다.
- **나이**: 2026-11 기준 만 나이. **키**: cm. **주발**: L 또는 R.
- **종합(ovr)** — 국가대표 데이터와 같은 잣대(EA·넥슨 수치를 베끼지 말고 직접 판단):
  - 90+: 세계 최정상 5~8명만 · 85~89: 빅클럽 핵심 주전 · 80~84: 강팀 주전 · 74~79: 중위권 주전 / 강팀 후보 · 65~73: 하위권 주전·후보 · 60~64: 유망주
  - 팀 선발 11명 평균 목표: 우승 경쟁 팀 83~86 · 유럽 대항전 팀 79~82 · 중위권 76~78 · 하위권·승격팀 72~75 (검증기가 평균을 출력한다)
- **꼬리표**(띄어쓰기로 여럿, 없어도 됨):
  - `pac+` `sho-` `pas++` … : 그 지표를 포지션 틀보다 높게/낮게(부호 하나에 4, 최대 셋). 지표 = pac 속력·sho 슈팅·pas 패스·dri 드리블·def 수비·phy 피지컬. 종합은 그대로 유지된다(올린 만큼 다른 지표가 조금 내려간다). 선수의 개성이 뚜렷할 때만.
  - `w1`~`w5` 약발(기본 3, 양발 5) · `s1`~`s5` 개인기(기본: GK 1·CB 2·그 밖 3, 종합 84 이상 공격 자원 4)
  - `alt:LW,CAM` 가능 포지션 · `?` 불확실(등번호·소속을 확인하지 못함)
- 백틱(`` ` ``)이나 `${`를 글 안에 쓰지 않는다. `#`로 시작하는 줄은 주석.
