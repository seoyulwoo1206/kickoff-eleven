# 킥오프 일레븐

11대11 풀경기 축구 게임. 24개 국가대표 팀, TV 중계 시점의 원근 카메라, 가속·회전 반경이 있는 선수 움직임, 질주 드리블(공을 앞에 차 놓고 쫓기), 오프사이드, 온라인 1대1.

## 실행
```bash
npm install
npm run dev
```
`http://localhost:5173` 을 연다. 같은 와이파이의 폰에서 해보려면 `npm run dev -- --host` 로 띄우고 터미널에 나오는 Network 주소로 접속.

- `npm run build` → `dist/` (정적 파일, 아무 호스팅에나 올리면 됨)
- `npm run typecheck` → TypeScript 검사
- `npm run sim [경기수] [경기길이초] [팀A] [팀B] [--seed N]` → 헤드리스 AI vs AI 통계 (예: `npm run sim 50 300 KOR BRA`)

이전 단일 파일 버전은 `legacy/index.html` (브라우저로 바로 열림).

## 선수단
24개 국가대표팀의 최근 소집 명단(23~26명, 등번호·포지션·주발·약발·개인기·키·능력치)이 `src/data/teams/*.json`에 있습니다. 각 파일의 `asOf`가 기준 날짜, `sources`가 참고한 출처입니다. 능력치는 실제 기량·소속팀·평판을 보고 직접 추정한 값이며(다른 게임 수치를 베끼지 않음), 선발·포메이션도 최근 경기 기준입니다. 메뉴의 "선수 이름"을 가명으로 바꾸면 이니셜로 표시됩니다. 검증: `npx tsx tools/validate-data.ts`.

## 폰에서
홈 화면에 추가하면 전체화면 앱처럼 실행되고 오프라인에서도 열립니다(PWA, https 배포 기준). 메뉴에서 조이스틱 끝 질주·진동·버튼 크기·투명도를 바꿀 수 있고, "라인업 · 선수 카드"에서 선발을 바꾸고 선수 능력치를 볼 수 있습니다.

## 전술·교체·규칙
메뉴에서 양 팀의 포메이션(4-4-2 · 4-3-3 · 4-2-3-1 · 3-5-2 · 5-3-2 · 3-4-3 · 4-1-4-1), 수비 라인, 공격 성향(균형/점유/역습/측면), 압박 강도를 고를 수 있고, 일시정지 메뉴에서 내 팀 전술을 바꾸거나 교체(최대 5명)할 수 있습니다. 파울엔 어드밴티지·경고·퇴장(10명으로 경기)·추가시간이 있고, 프리킥은 벽이 서고 자동으로 감아차며, 페널티킥은 키퍼가 한쪽을 찍습니다. AI 난이도는 속도 치트 없이 반응 시간·실수·압박·태클·키퍼로만 달라집니다.

## 대전 방식
| 방식 | 설명 |
|---|---|
| AI 대전 | 난이도 쉬움/보통/어려움 |
| 2인 대전 (한 키보드) | P1 방향키 + S/A/W/D/Z/Q/E, P2 IJKL + B/V/N/M/./,/Space |
| 월드컵 | 내 팀으로 6조 조별리그 → 16강 → 결승. 다른 경기는 자동 진행, 진행 상황은 브라우저에 저장. 토너먼트는 비기면 연장 → 승부차기 |
| 승부차기 | 5개씩 번갈아 차고 서든데스. 수비 땐 스틱 위/아래로 키퍼 다이브 방향 |
| 온라인 대전 | 한쪽이 **방 만들기** → 4글자 코드가 나옴 → 상대가 코드를 넣고 **참가**. 호스트가 왼쪽 팀, 게스트가 오른쪽 팀. 둘 다 P1 키(또는 터치·패드)로 조작 |

온라인은 WebRTC(PeerJS)로 두 브라우저가 직접 연결됩니다. 방 코드 교환에만 PeerJS 공개 시그널링 서버를 쓰고, 경기 데이터는 P2P로 오갑니다. 호스트가 경기를 계산하고 게스트는 입력만 보내므로 핑(HUD에 표시)이 낮을수록 반응이 빠릅니다.

## 조작 (FC 온라인 배치)
| | 키보드 | 게임패드 | 공격 | 수비 |
|---|---|---|---|---|
| 이동 | 방향키 | 왼스틱·십자키 | 이동 | 이동 |
| pass | S | A | 짧은 패스 | 압박(길게) / 태클 |
| lob | A | Y | 롱패스 · 크로스 | 선수 전환 |
| through | W | X | 스루패스 | 세컨드 디펜더(길게) |
| shoot | D | B | 슛(길게 파워) | 슬라이딩 태클 |
| chip | Z | LB | 칩슛 | - |
| run | Q | LT | 침투 지시 (스틱 방향 동료가 뒷공간으로, 노란 화살표) | 압박 지원 (동료가 같이 압박, 빨간 화살표) |
| gkRush | X | L3 | 개인기 (탭: 헛다리 · 뒤로+탭: 드래그백 · 질주 중 옆+탭: 마르세유 턴 / 누른 채 슛: 감아차기) | 골키퍼 돌진 |
| sprint | E | RB / RT | 질주 (공 잡고 질주하면 공을 앞에 치고 나감) | 질주 |

패스는 떼는 순간 나가고 누른 시간이 세기입니다. 개인기는 선수의 개인기 등급(1~5)에 따라 되는 기술이 다릅니다. 질주하면 체력이 닳아 후반엔 느려집니다 (커서 아래 초록 바).

메뉴의 **키 설정**에서 P1 키를 바꿀 수 있습니다. P / Esc / Start 일시정지. 폰은 왼쪽 화면 아무 데나 누르고 밀면 조이스틱(살짝 밀면 걷기), 오른쪽에 패스(짧게 숏/길게 롱)·슛(길게 파워)·스루·질주 버튼, 오른쪽 빈 공간을 스와이프하면 개인기. 수비 땐 버튼이 압박·슬라이딩·전환으로 바뀝니다.

## 배포 (GitHub Pages)

**플레이 주소: https://seoyulwoo1206.github.io/kickoff-eleven/** (저장소: https://github.com/seoyulwoo1206/kickoff-eleven)

`main` 브랜치에 올리면 `.github/workflows/deploy.yml`이 빌드해서 GitHub Pages에 올립니다. 주소는 `https://<계정>.github.io/<저장소 이름>/`.

1. GitHub에 빈 저장소를 만든다 (무료 계정은 공개 저장소여야 Pages가 된다).
2. 저장소 Settings → Pages → Build and deployment → Source 를 **GitHub Actions** 로 바꾼다 (한 번만).
3. `git remote add origin <저장소 주소>` 뒤 `git push -u origin main`.
4. Actions 탭에서 "Deploy to GitHub Pages"가 끝나면 주소가 열린다. 이후엔 `git push`만 하면 다시 배포된다.

모든 경로가 상대 경로(`vite.config.ts`의 `base: './'`)라 저장소 이름이 무엇이든 그대로 동작합니다. 서비스 워커 캐시 이름은 배포 때 커밋 해시로 바뀌어 옛 캐시가 지워집니다.
