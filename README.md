# 킥오프 일레븐

11대11 풀경기 축구 게임. 24개 국가대표 팀, TV 중계 시점의 원근 카메라, 가속·회전 반경이 있는 선수 움직임, 질주 드리블(공을 앞에 차 놓고 쫓기), 오프사이드, 온라인 1대1.

## 실행
```bash
npm install
npm run dev
```
`http://localhost:5173` 을 연다. 같은 와이파이의 폰에서 해보려면 `npm run dev -- --host` 로 띄우고 터미널에 나오는 Network 주소로 접속.

- `npm run build` → `dist/` (정적 파일, 아무 호스팅에나 올리면 됨)
- `npm run typecheck` → TypeScript 검사
- `npm run sim [경기수] [경기길이초] [팀A] [팀B] [--seed N]` → 헤드리스 AI vs AI 통계 (예: `npm run sim 50 300 KOR BRA`)

이전 단일 파일 버전은 `legacy/index.html` (브라우저로 바로 열림).

## 대전 방식
| 방식 | 설명 |
|---|---|
| AI 대전 | 난이도 쉬움/보통/어려움 |
| 2인 대전 (한 키보드) | P1 방향키 + S/A/W/D/Z/Q/E, P2 IJKL + B/V/N/M/./,/Space |
| 온라인 대전 | 한쪽이 **방 만들기** → 4글자 코드가 나옴 → 상대가 코드를 넣고 **참가**. 호스트가 왼쪽 팀, 게스트가 오른쪽 팀. 둘 다 P1 키(또는 터치·패드)로 조작 |

온라인은 WebRTC(PeerJS)로 두 브라우저가 직접 연결됩니다. 방 코드 교환에만 PeerJS 공개 시그널링 서버를 쓰고, 경기 데이터는 P2P로 오갑니다. 호스트가 경기를 계산하고 게스트는 입력만 보내므로 핑(HUD에 표시)이 낮을수록 반응이 빠릅니다.

## 조작 (FC 온라인 배치)
| | 키보드 | 게임패드 | 공격 | 수비 |
|---|---|---|---|---|
| 이동 | 방향키 | 왼스틱·십자키 | 이동 | 이동 |
| pass | S | A | 짧은 패스 | 압박(길게) / 태클 |
| lob | A | Y | 롱패스 · 크로스 | 선수 전환 |
| through | W | X | 스루패스 | 세컨드 디펜더(길게) |
| shoot | D | B | 슛(길게 파워) | 슬라이딩 태클 |
| chip | Z | LB | 칩슛 | - |
| gkRush | Q | LT | - | 골키퍼 돌진 |
| sprint | E | RB / RT | 질주 (공 잡고 질주하면 공을 앞에 치고 나감) | 질주 |

P / Esc / Start 일시정지. 폰은 왼쪽 화면 아무 데나 누르고 밀면 조이스틱(살짝 밀면 걷기), 오른쪽에 패스(짧게 숏/길게 롱)·슛(길게 파워)·스루·질주 버튼. 수비 땐 버튼이 압박·슬라이딩·전환으로 바뀝니다.
